# SPA Salón — Landing page

Landing page para un spa con secciones de promociones, productos, instalaciones, bolsa de trabajo y suscripción a noticias.

## Funcionalidades
- Diseño de página única con varias secciones.
- Formulario de suscripción con **validación del correo electrónico** (campo vacío y formato con expresión regular) usando jQuery.

## Tecnologías
HTML · CSS · JavaScript · jQuery

## Ejecutar
Abrir `index.html` en el navegador.
